# Сохранение экспериментальной итерации

Дата фиксации: 9 октября 2026 года, Europe/Moscow.

Репозиторий [uprava-legacy](https://github.com/zaryalabs/uprava-legacy)
сохраняет завершённый эксперимент. Сам проект Uprava продолжается; чистовая
реализация будет развиваться отдельно.

## Код и история

Финальный implementation baseline — `0.2.26`, исходный commit
`9d096834eadfacd9f04a551c5557b33194e7ca4b`. Этот commit — основание
[ретроспективы](README.md) и [рекомендаций следующей итерации](next-iteration.md).
Исполняемый код снимка сохранён без изменения; сохранение документации не
меняет implementation version и не является новым production release.

Локальные ветки исходного checkout закреплены отдельными ветками:

| Исходная ветка | Ветка сохранения | Commit |
| --- | --- | --- |
| `main` | `codex/experiment-01-main` | `bcca51cc808a17cb0469c14a4bc4d87dbba10877` |
| `tools` | `codex/experiment-01-tools` | `78fab52f32ebdf11cf86d5cce47338a5c8eb195d` |
| `sessions` | `codex/experiment-01-sessions` | `9d096834eadfacd9f04a551c5557b33194e7ca4b` |

Ветка сохранения финального снимка — `codex/preserve-uprava-experiment`,
тег — `experiment-01-final`. В снимок объединены финальная реализация и
переименование репозитория из GitHub `main`, добавлены 25 документов
ретроспективы и исследования, а также связанные изменения документации.

## CI/CD

Старый workflow отключён в настройках GitHub до публикации материалов.
Его исходная конфигурация сохранена как
[исторический файл](legacy-ci/ci.yml), вне `.github/workflows/`.
Этот снимок не должен автоматически собирать или развёртывать эксперимент
при обновлении документации.

## Приватные материалы и серверное состояние

Локальные рабочие заметки, история в `.local/`, журналы и приватные файлы,
а также серверные базы, blobs, workspaces и необходимые конфигурации
сохраняются отдельно в зашифрованных архивах владельца, вне Git.
Файл ключа хранится отдельно от архивов с ограниченными правами доступа.

SQLite сохраняется через online backup API с проверкой целостности.
Архивирование выполняется без остановки сервисов; это не единый атомарный
снимок всех файлов работающей системы. Перед фактическим удалением
серверного состояния требуется финальный снимок после прекращения записи.

## Проверка сохранения

Для проверки следует клонировать GitHub-репозиторий на тег
`experiment-01-final`, проверить наличие исходного commit и историю,
совпадение исполняемого кода с baseline `0.2.26`, полноту пакета и
локальные ссылки командой `make docs-l`. Архивы проверяются полной
расшифровкой, чтением tar и проверкой целостности снимков SQLite.

Сохранение не отменяет результаты прежних проверок. Известные ограничения
quality gate остаются в [журнале экспериментов](research/experiments.md).

## Проверки при сохранении 9 октября

- `make docs-l`: локальные ссылки корректны, 79 Markdown-файлов.
- `git diff --check`: ошибок пробелов нет.
- 25 исходных документов ретроспективы сохранены побайтно.
- Исполняемый код совпадает с commit `9d096834eadfacd9f04a551c5557b33194e7ca4b`.
- Gitleaks: новые коммиты и пакет проверены; два срабатывания на прежний
  описательный текст о content tokens/renderers проверены как false positives.
- Повторный `make c` прошёл format, Markdown links, Rust clippy, Web lint/typecheck
  и protocol drift check. Он остановился на известном `rustls 0.23.40`,
  `RUSTSEC-2026-0285`. Полный gate не пройден; тестовая цель в этом запуске
  не достигнута. Исходные зависимости сохранены для воспроизводимости эксперимента.
- Закрытые архивы проверены AES-GCM authentication, чтением tar и SHA-256
  каждого файла: серверный пакет содержит 9589 файлов и 8 снимков SQLite,
  локальный — 148 файлов и 1 снимок SQLite. Все снимки прошли `integrity_check`.

# Исследование подходов для следующей итерации

Исследование сравнивает решения, которые помогут сделать узкую панель облачных
агентов отзывчивой, безопасной и расширяемой. Основной обзор выполнен
3 октября 2026 года; 7 октября добавлен source review DeepSeek Harness.
Под SOTA здесь понимается выборка актуальных первичных источников и подходов,
пригодность которых проверяется относительно нашей задачи. Исчерпывающий
рейтинг рынка или доказательство превосходства одного продукта не заявляются.

## Метод и ограничения

Исследование опирается на официальную документацию, спецификации, release
notes и выбранные участки исходного кода. Углублённый этап прослеживает
реализации T3 Code, OpenCode, ToolHive и DeepSeek Harness на закреплённых commit, включая
тесты интересующих контрактов. Upstream-приложения и их тесты не запускались.
Документированный контракт, найденная реализация и наша рекомендация
различаются в тексте каждого разбора.

Каждый внешний источник имеет URL, дату чтения и доступную версию в
[реестре](sources.md). Для четырёх углублённо изученных проектов зафиксированы
immutable SHA и ссылки на строки. У вспомогательных материалов обзора
редакторов и модульности остаются явно отмеченные moving-ссылки. История
`0.2.26` не переписывается по сегодняшним версиям MCP или provider API.

Сравнение выполнено по одинаковым вопросам: владелец состояния, границы
доверия, актуальность UI, восстановление, lifecycle, совместимость,
эксплуатационная цена. Популярность и количество функций не используются
как доказательство качества.

## Граница между выводом и экспериментом

Документы и код уже позволяют рекомендовать явное ownership, отдельные
контракты выполнения и отказ от молчаливого unsafe fallback. Они не позволяют
назначить победителя по latency, доказать безопасность cloud deployment или
выбрать редактор по скорости. Для таких решений заданы отдельные протоколы
испытаний. Невыполненный эксперимент остаётся открытым, а не заменяется
положительным выводом из наличия теста.

Углублённый этап по запросу владельца ограничен чтением реализаций и
рекомендациями. Его результат позволяет написать короткие ADR следующей
итерации. Практические протоколы сохранены как возможная последующая
приёмка; их выполнение не является частью этого source review.
